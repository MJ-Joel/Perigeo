# Perigeo

Agenda de contactos multiplataforma desarrollada íntegramente en C# con .NET 11.

## Sobre el proyecto

Perigeo funciona en Android, iOS, Windows, macOS y web con un único código de interfaz, y se apoya en una API REST propia para gestionar los datos.

Su nombre viene de la astronomía: el perigeo es el punto de una órbita más cercano a la Tierra. A diferencia de una agenda tradicional, que ordena los contactos alfabéticamente, Perigeo los organiza según su cercanía contigo. Las personas con las que más interactúas orbitan más cerca, y cada contacto tiene un color propio que define su identidad visual.

## Tecnologías

- C# y .NET 11
- .NET MAUI Blazor Hybrid y Blazor Web App
- ASP.NET Core Web API
- Entity Framework Core con SQLite
